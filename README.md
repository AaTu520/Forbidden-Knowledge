# 禁忌学识

为 RPG Series 法杖、弓和弩提供锻造强化与法术贯通属性。

## 成品

Minecraft 1.21.1。

- NeoForge [forbidden_knowledge-1.0.5-neoforge.jar](artifacts/neoforge/forbidden_knowledge-1.0.5-neoforge.jar)
- Fabric [forbidden_knowledge-1.0.4-fabric.jar](artifacts/fabric/forbidden_knowledge-1.0.4-fabric.jar)

[安装前置、强化与配置](GUIDE.md)

## 构建

将 [AaTu-EXUp](https://github.com/AaTu520/AaTu-EXUp) 克隆到同一父目录，保留文件夹名 `AaTu-EXUp`。

使用 JDK 21，进入 `fabric/` 或 `neoforge/` 后执行 `.\gradlew.bat assemble -x test`。
